# Visa Lounge

Next.js application for visalounge.in.

This repository is separate from My Travel Company.

## Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
npm run typecheck
```

Open [http://localhost:3000](http://localhost:3000) after `npm run dev`.

## Stack

- Next.js 15 (App Router)
- React 19
- TypeScript
- Tailwind CSS 4
- ESLint
